# ISEKAI COLLECTION

A personal site where I store a collection of my favourite things, built from scratch as my first web project.

**Live site:** https://isekaico.netlify.app

![Emilia's character page](screenshots/charpage.gif)

## Features
- Music page with time-synced lyrics (fetched from the LRCLIB API)
- Built-in music player (top right) with a full-screen view and live audio visualizer
- Hover a song on the home page to hear a short preview
- Video background on the home page
- English / Japanese language switch
- Character art with a hovering animation

## Built with
- HTML, CSS, JavaScript (no frameworks)
- Python + ffmpeg script for preparing song lengths and cover thumbnails
- Hosted on Netlify

## Note
Media files (songs, videos, artwork) aren't included in this repo for copyright reasons. See the live site for the full experience.
